# ДЗ №2 - Микроконтроллеры. Вводный курс

Краткое описание работы.

## Что требовалось по заданию

1. Переписать программу, чтобы светодиод менял своё состояние от нажатия кнопки через прерывание

## Аппаратная часть

- Микроконтроллер: **STM32F103C8T6**.

## Что сделано

- Среда: STM32CubeIDE, проект `hw2` (генератор кода CubeMX).
- GPIO: 
:два вывода на выход:
  - `LED1` - PB14;
  - `LED2` - PB15;
:два вывода на вход с активированным прерыванием, pull-up включен.
  - `SW1`  - PB12;
  - `SW2`  - PB13;
- Отладка: SWD на PA13 (SWDIO) / PA14 (SWCLK), режим `Serial_Wire`.

- Логика в `main` (в суперцикле `while (1)`) - вкл/выкл светодиодов по нажатию кнопки, SW1 управляет LED1, а SW2 управляет LED2.
- Для защиты от дребезга добавлено окно блокировки, после первого нажатия последующие игнорируются в пределах 100мс, функция HAL_GetTick() возвращает время в мс после старта МК.
- Флаги sw1_event/sw2_event устанавливаются в обработчике прерываний.
  ```c
	  if (sw1_event)
	  {
		sw1_event =0;
		if (HAL_GetTick()-sw1_last_tick>100)
		  {
			sw1_last_tick = HAL_GetTick();
			HAL_GPIO_TogglePin(GPIOB, LED1_Pin);
		  }

	  }
	  if (sw2_event)
	  {
		sw2_event =0;
		  if (HAL_GetTick()-sw2_last_tick>100)
		    {
			  sw2_last_tick = HAL_GetTick();
			  HAL_GPIO_TogglePin(GPIOB, LED2_Pin);
		    }
	  }
  ```

  Обработчик прерываний:
```c
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
        if (GPIO_Pin == SW1_Pin)
        {
                sw1_event = 1;
        }
        else if (GPIO_Pin == SW2_Pin)
        {
                sw2_event = 1;
        }
}
```
